The base install supports the proven mounted-NFSv4 target without any cloud SDK.

```toml

target_id = "nas-a"
target_root = "/srv/edge-evidence-replica"
```

Run with a target config:

```bash
replication-worker run \
  --database edge.sqlite3 \
  --spool-root spool \
  --target-config replication.toml
```

The GCS adapter is optional:

```bash
python -m pip install 'edge-evidence-replication-worker[gcs]'
```


Credentials. Tokens, service-account keys, credential files, and other secret
material are not target-config fields and do not belong in this repository.
