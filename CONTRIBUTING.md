# Contributing

This repository is a deterministic projection of `Seemorghdev/edge-evidence-platform`.

Please report issues here if useful, but source fixes are authoritative only
when made in the canonical monorepo and re-exported. Do not add credentials,
tokens, private host paths, provider secrets, Terraform state, or retained
acceptance evidence to this projection.

For code changes, preserve the replication worker's immutable-publication and
fail-closed verification semantics and submit the authoritative change
upstream first.
